Creates bootable USB drives from ISO files — Windows 10, Windows 11, Ubuntu, or any other OS. Supports both GPT (UEFI) and MBR (Legacy BIOS) partition schemes.

## Features

- Supports GPT+UEFI and MBR+BIOS boot modes
- Works with Windows 10, 11, and any Linux distro ISO
- Windows 11 TPM bypass option built in
- Verifies ISO integrity before writing
- Write speed progress with time remaining estimate

## FAQ

**Will it erase everything on the USB?**  
Yes — the USB will be completely formatted. Back up anything on it first.

**How do I boot from the USB after?**  
Restart your PC and press F11/F12 (or Del/F2 for BIOS) to select boot device. Choose your USB.

## Requirements

- Windows 10 / 11 (64-bit)
- USB drive (8 GB minimum), ISO file for the OS you want to install
