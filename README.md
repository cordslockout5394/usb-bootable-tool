## ❓ Frequently Asked Questions

### Is this tool safe?

Yes. The application does not modify your system files and works entirely with your USB drive. It does not contain malware or bundled software.

### Do I need administrator rights?

For most operations, yes. If you see a User Account Control (UAC) prompt, click **"Yes"** to allow the tool to access your USB drive.

### Will this erase my USB drive?

Yes, the tool will format your USB drive and delete all existing data on it. **Back up any important files before proceeding.**

### Can I use this to create a Linux bootable USB on Windows?

Absolutely. The tool supports Ubuntu, Linux Mint, and many other Linux distributions. Just select the ISO file you downloaded from the official Linux distribution website.

### What if my computer doesn't recognize the USB drive after creation?

Try plugging it into a different USB port. On some older PCs, you may need to press a key (F12, F2, or Del) during startup to choose the boot device.

## 📚 How to Use Your Bootable USB

Once your USB drive is ready, follow these steps to boot from it:

1. **Restart your computer.**
2. **Enter the boot menu** — usually by pressing `F12`, `F2`, `Esc`, or `Del` immediately after turning on your PC (check your computer's manual).
3. **Select your USB drive** from the boot menu.
4. **Follow the on-screen instructions** to install your operating system.

That is it. You have now created a fully functional bootable USB drive.
